# Лабораторная работа №3. Линейные модели

## 1. Данные и подготовка

Цель работы — самостоятельно реализовать линейную и логистическую регрессию с помощью градиентного спуска, обучить модели и сравнить полученные результаты.

Для линейной регрессии использовался датасет Student_Performance.csv, содержащий 10000 записей. Целевая переменная — Performance Index. Признак Extracurricular Activities преобразован из Yes/No в 1/0.

Для логистической регрессии использовался german.csv, содержащий 1000 записей о клиентах банка. Целевая переменная — Creditability (0 или 1).

Оба набора данных разделены на обучающую (80%) и тестовую (20%) выборки с random_state=42. Для кредитного датасета использовалась стратификация по целевому классу.

Признаки масштабированы с помощью StandardScaler. Параметры масштабирования вычислялись только на обучающей выборке.

## 2. Гипотезы и эксперименты

Предполагалось, что линейная регрессия сможет достаточно точно предсказывать успеваемость студентов, а логистическая регрессия — различать два класса кредитоспособности.

Линейная регрессия реализована самостоятельно с использованием пакетного градиентного спуска. Скорость обучения — 0.05, количество эпох — 800. Ошибка MSE на обучении уменьшилась с 3428.035 до 4.170.

Логистическая регрессия также реализована самостоятельно. Использованы сигмоидная функция, бинарная кросс-энтропия и пакетный градиентный спуск. Скорость обучения — 0.1, количество эпох — 1000. Ошибка уменьшилась с 0.6931 до 0.4821.

Дополнительно были обучены три готовые модели: LogisticRegression, DecisionTreeClassifier и KNeighborsClassifier. Для сравнения использовались те же обучающая и тестовая выборки.

Для дерева решений применялась максимальная глубина 5, для KNN — 5 соседей, для LogisticRegression — max_iter=1000.

## 4. Выводы

Удалось реализовать линейную и логистическую регрессию без использования готовых моделей sklearn внутри собственных алгоритмов.

Линейная регрессия показала небольшую среднюю квадратичную ошибку на тестовых данных.

Собственная логистическая регрессия достигла Accuracy 77% и ROC-AUC 0.8081. Результаты практически совпали с готовой LogisticRegression из sklearn.

DecisionTreeClassifier и KNeighborsClassifier показали меньшие Accuracy, F1 и ROC-AUC. При этом дерево решений получило более высокий Precision.

Одна из возможных причин различий — особенности алгоритмов и выбранные параметры. Также использование числовых кодов категориальных признаков может влиять на качество моделей.
